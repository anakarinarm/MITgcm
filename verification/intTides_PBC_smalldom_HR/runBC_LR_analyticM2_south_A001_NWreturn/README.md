# LR analytical M2 forcing: south A0=0.01 m/s, north+west return

This is the lower-amplitude analytical south-forcing experiment with the
compensating return flow distributed over both north and west.

Architecture:

- no SSH;
- south normal M2 velocity with `A0 = 0.01 m/s`;
- 10-cell cosine taper near south corners;
- north receives weak uniform return;
- west receives weak uniform return/outflow, represented by a half-period
  phase lag in the west `u` tide;
- Stevens/radiative W/S/N;
- strong 20-cell momentum sponge.

Generated by:

```bash
python3 prepare_analytic_south_tide_A001.py
```

Generation diagnostics:

- south max/RMS amplitude: `0.0100 / 0.00968 m/s`
- north return max/RMS amplitude: `0.004996 / 0.00377 m/s`
- west return max/RMS amplitude: `0.004996 / 0.004996 m/s`
- west return phase lag: `22356 s` = half an M2 period
- transport residual `Q_W + Q_S - Q_N`: `0.0 m3/s`

This test asks whether spreading the return flow reduces north-boundary
artifacts without reintroducing strong west-boundary forcing.

Run and analyze:

```bash
mpiexec -n 16 ./mitgcmuv
python3 check_boundary_reflections.py
python3 modal_characteristic_decomposition.py
```

Compare against:

- `../runBC_LR_analyticM2_south_A001_Nreturn`
- `../runBC_LR_analyticM2_south_A002`
- `../runBC_LR_noSSH_noW_strongSponge`

## Result

The run completed normally; STDERR only contained the harmless retired
`EXACT_CONSERV` warning.

Distributing the return over north+west strongly reduced north-boundary energy
and produced the cleanest ETAN of the family, but also weakened the south
internal tide and left the west far-section relatively inward dominated.

At offset 22 cells:

| boundary | mode-1 outward/inward | incoming fraction | bulk flux |
|---|---:|---:|---:|
| W | `1.76 / 1.95 MW` | `0.526` | `+0.218 MW` |
| S | `5.20 / 1.39 MW` | `0.211` | `+4.88 MW` |
| N | `0.089 / 0.086 MW` | `0.491` | `+0.099 MW` |

West mode 1 at offset 33 was `1.38 / 2.63 MW`, incoming fraction `0.656`.

Final ETAN:

- min/max: `-0.0044 / +0.0057 m`
- mean: `+0.00005 m`
- RMS: `0.00185 m`

Interpretation: the north+west return is excellent for barotropic cleanliness
and reducing north-boundary contamination, but it may under-force the internal
tide for the current `A0=0.01 m/s` amplitude.  It also reintroduces a weak west
return flow, so the west far-section incoming fraction is not obviously better
than the north-only return case.
