# LR full-TPXO SSH + velocity boundary test

This is the Ponte & Cornuelle-style boundary-condition test motivated by:

Ponte, A. L. and Cornuelle, B. D. (2013), *Coastal numerical modelling of tides:
Sensitivity to domain size and remotely generated internal tide*, Ocean
Modelling, 62, 17--26.

The point of this run is to test whether the boundary problem is partly caused
by prescribing barotropic velocity without prescribing the dynamically
consistent sea-surface-height tide.  The previous LR control,
`../runBC_LR_fullTPXO_balanced`, uses `useOBCStides=.TRUE.` and lets model SSH
adjust.  This test instead prescribes both SSH and barotropic velocity as OBCS
time records on the same M2 clock.

## First failed attempt and fix

The first run with prescribed SSH did not fail while reading OBCS files.  MITgcm
successfully opened the OBCS velocity, T/S, and SSH records.  It stopped later,
at iteration 59, in `CALC_R_STAR`:

```text
rStarFacS,H,eta = 0.180396  3.000000E-01  -3.992987E-01 ...
STOP in CALC_R_STAR : too SMALL rStarFac[C,W,S] !
```

This means the nonlinear free surface tried to shrink a very shallow wet cell
below the allowed r* thickness.  The original LR telescopic bathymetry includes
sub-meter wet slivers; that is incompatible with an O(0.4 m) prescribed SSH
tide unless we explicitly want wetting/drying/tidal-flat dynamics, which we do
not for this internal-tide boundary-condition test.  The fix is the run-specific
minimum-wet-depth bathymetry described above.  I chose deepening rather than
turning those cells into land so the boundary wet mask and OBCS file dimensions
remain unchanged.

## What to compare

Compare primarily against:

- `../runBC_LR_fullTPXO_balanced`
- `../runBC_LR_south_dominant`

The useful first-order metrics are:

- domain-mean ETAN M2 amplitude;
- west-boundary mode-1--5 inward/outward characteristic energy;
- whether west inward dominance weakens at offsets 22 and 33;
- whether the SSH-clamped setup creates a new volume/ETAN pathology because
  the east side is closed.

If this run improves the west modal-characteristic split without creating a big
ETAN amplification, it becomes the best candidate boundary architecture to
port back to the HR telescopic sponge case.

## Result after rerun with minimum-depth bathymetry

The rerun passed the previous `CALC_R_STAR` failure and completed the planned
short LR test.  The only `STDERR.*` messages were the existing retired
`EXACT_CONSERV` compile-option warnings.

The SSH+velocity full-boundary setup did improve one very specific diagnostic:
the west modal-characteristic split is now nearly symmetric rather than
strongly inward-dominated.  For example, at the west boundary and 22-cell
offset, mode 1 has inward/outward amplitude about 0.99 and incoming energy
fraction about 0.50.

However, this is not yet a good production boundary setup.  The absolute
characteristic energies are orders of magnitude larger than in the previous LR
controls, and the bulk flux/reflection diagnostic shows large net inward
behavior at the northern boundary.  The OBCS monitor also shows large
barotropic transport imbalances because this test used raw TPXO velocities with
a closed eastern side:

```text
obc_W_uVel_Int ~ +1.8e6 m3/s
obc_N_vVel_Int ~ -7.1e5 m3/s
obc_S_vVel_Int ~ -1.8e6 m3/s
```

Interpretation: prescribing SSH helped with the phase/characteristic symptom at
the west boundary, but prescribing raw full-boundary TPXO SSH plus raw TPXO
velocity is over-constraining and barotropically imbalanced for this regional
domain.  The next cleaner test should keep the prescribed SSH idea, but combine
it with volume-balanced/relaxed velocities rather than raw velocity records on
all open boundaries.
