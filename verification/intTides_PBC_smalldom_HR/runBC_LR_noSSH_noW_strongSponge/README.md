# LR no-SSH forcing architecture test: no west prescribed velocity

This test starts from `runBC_LR_noSSH_sponge_strong`.

Everything is unchanged except the harmonic tidal forcing:

- west remains an open OBCS boundary;
- west keeps Stevens/radiative behavior;
- west keeps the momentum sponge;
- prescribed west normal M2 velocity is set to exactly zero;
- south and north M2 normal velocities are rebalanced to close complex
  barotropic transport.

The purpose is to test whether the west inward modal-energy excess is tied to
prescribing TPXO-like normal velocity on the west boundary.

## Generated forcing files

Created by:

```bash
python3 prepare_noW_balanced_tides.py
```

Output files:

- `../input/OBWuam_M2_noW_balanced_LR220x240_telescopic20.bin`
- `../input/OBWuph_M2_noW_balanced_LR220x240_telescopic20.bin`
- `../input/OBSvam_M2_noW_balanced_LR220x240_telescopic20.bin`
- `../input/OBSvph_M2_noW_balanced_LR220x240_telescopic20.bin`
- `../input/OBNvam_M2_noW_balanced_LR220x240_telescopic20.bin`
- `../input/OBNvph_M2_noW_balanced_LR220x240_telescopic20.bin`

Generation diagnostics:

- west max amplitude: `0.0 m/s`
- no-west raw complex transport: `1.69e6 m3/s`
- S/N correction amplitude: `0.00840 m/s`
- no-west balanced residual: `3.3e-10 m3/s`

## Run and analyze

```bash
mpiexec -n 16 ./mitgcmuv
python3 check_boundary_reflections.py
python3 modal_characteristic_decomposition.py
```

Compare primarily against:

- `../runBC_LR_noSSH_sponge_strong`
- `../runBC_LR_recommended_noSSH_balanced_radiative`

Interpretation:

- If west inward mode-1 energy drops substantially, west prescribed velocity
  was driving or phase-locking the problematic west signal.
- If west remains inward-dominated, the signal is more likely generated by
  interior/topographic response or by interactions with south/north forcing,
  and we should test south-only/south-dominant variants next.

## Result

The run completed normally; STDERR only contained the harmless retired
`EXACT_CONSERV` warning.

Removing prescribed west velocity substantially improved the west modal
diagnostic.

West mode-1 comparison:

| run | offset 22 | offset 33 |
|---|---:|---:|
| noW + strong sponge | 4.00 / 3.98 MW, frac 0.498 | 3.48 / 5.45 MW, frac 0.610 |
| full W/S/N + strong sponge | 7.26 / 7.63 MW, frac 0.512 | 5.70 / 10.55 MW, frac 0.649 |
| original baseline | 7.11 / 7.75 MW, frac 0.522 | 5.51 / 10.51 MW, frac 0.656 |

The west bulk flux also became less inward at the far offset:

| run | W flux offset 22 | W flux offset 33 |
|---|---:|---:|
| noW + strong sponge | `+1.01 MW` | `-1.58 MW` |
| full W/S/N + strong sponge | `+1.18 MW` | `-4.18 MW` |
| original baseline | `+0.84 MW` | `-4.47 MW` |

Tradeoffs:

- S mode-1 outward energy at offset 22 dropped from about `20.6 MW` in the
  full W/S/N strong-sponge run to `10.4 MW`.
- Final ETAN RMS increased modestly from `0.0090 m` to `0.0115 m`, with a
  negative mean bias of about `-0.0078 m`.

Interpretation: prescribed west velocity is a major contributor to the west
inward modal-energy excess.  However, simply removing west forcing and
redistributing the transport correction over S/N changes the south forcing and
introduces a small ETAN bias.  This is a strong diagnostic result, but probably
not yet the final production forcing.
