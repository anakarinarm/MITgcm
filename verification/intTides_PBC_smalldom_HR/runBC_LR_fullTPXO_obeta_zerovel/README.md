# LR full-TPXO SSH + zero velocity diagnostic test

Purpose: isolate whether the large, nearly symmetric modal characteristic
energies in the SSH-clamped tests come from the imposed TPXO SSH itself rather
than from prescribed boundary velocity.

This run keeps the same LR telescopic grid, minimum-10 m obeta bathymetry,
prescribed TPXO M2 SSH, T/S boundary files, diagnostics, and 20-cell momentum
sponge used by the other obeta tests.

Difference from `runBC_LR_fullTPXO_obeta_weakvel010`:

- all six prescribed velocity records are exactly zero;
- SSH files remain full-amplitude TPXO M2 on W/S/N;
- `useOBCSbalance=.FALSE.` because zero normal velocity has zero net transport
  by construction.

Generated zero velocity files:

- `../input/OBWu_M2_fullTPXO_balanced_zerovel_LR220x240_telescopic20_obeta16.bin`
- `../input/OBWv_M2_fullTPXO_zerovel_LR220x240_telescopic20_obeta16.bin`
- `../input/OBSu_M2_fullTPXO_zerovel_LR220x240_telescopic20_obeta16.bin`
- `../input/OBSv_M2_fullTPXO_balanced_zerovel_LR220x240_telescopic20_obeta16.bin`
- `../input/OBNu_M2_fullTPXO_zerovel_LR220x240_telescopic20_obeta16.bin`
- `../input/OBNv_M2_fullTPXO_balanced_zerovel_LR220x240_telescopic20_obeta16.bin`

After completion, run:

```sh
python3 check_boundary_reflections.py
python3 modal_characteristic_decomposition.py
```

Expected diagnostic interpretation:

- If modal energies remain close to the weak-velocity SSH tests
  (`W mode-1 ~183 MW`, `S mode-1 ~85 MW`, `N mode-1 ~53 MW` with incoming
  fraction near 0.5), then full-amplitude SSH clamping is the source of the
  standing boundary signal.
- If modal energies collapse, then even weak velocity forcing was still
  responsible.

## Result after run

The run completed cleanly; STDERR only contained the harmless retired
`EXACT_CONSERV` warning.

At offset 22 cells, bulk outward fluxes from `check_boundary_reflections.py`
were essentially zero:

- W: `-5.7e-12 MW`
- S: `+9.3e-12 MW`
- N: `-4.5e-12 MW`

The modal characteristic decomposition still showed the same large, exactly
standing signal seen in the weak-velocity SSH tests:

- W mode 1: `182.47 / 182.47 MW`, incoming fraction `0.500000`
- S mode 1: `84.98 / 84.98 MW`, incoming fraction `0.500000`
- N mode 1: `53.12 / 53.12 MW`, incoming fraction `0.500000`

For comparison, the `alpha = 0.10` weak-velocity run differed from this
zero-velocity run by only about `0.1--0.3%` in mode-1 characteristic energy.

Final saved ETAN range was approximately `-0.425 to +0.000006 m`, with RMS
`0.0407 m`, again matching the SSH-clamped tests and not the no-SSH balanced
case.

Interpretation: the large near-standing boundary-characteristic signal is
generated by prescribing full-amplitude TPXO SSH at the open boundaries.  It is
not caused by prescribed boundary velocity, even weak prescribed velocity.
This strongly argues against using full-boundary SSH clamping for the
production internal-tide configuration unless a different radiation/relaxation
formulation is implemented.
